# Поиск клиентов · Яндекс.Карты

Десктопное приложение: ищет организации на Яндекс.Картах, оставляет те, у
которых **нет своего сайта**, и выгружает их в Excel/CSV/JSON/карту — чтобы
предложить им услуги. Работает локально: Flask-сервер поднимается на
`127.0.0.1`, браузер пользователя открывает единственную страницу.

## Как открыть это хранилище

Obsidian → **Open folder as vault** → выбрать папку `docs/obsidian`.
Все заметки связаны перекрёстными ссылками; начните с этой.

## Что важно помнить

- Поиск читает **настоящий браузер** на Chromium через CDP; без него
  приложение не работает и честно об этом говорит.
- Координаты пишутся в каждую выгрузку — иначе вкладка «На карте» пустая.
- `output/_seen.json` помнит уже найденные организации: повторный прогон
  по тому же городу может дать «ничего нового».
- Данные пользователя (результаты, логи, настройки, ключи) — рядом с
  приложением, а не в репозитории.
