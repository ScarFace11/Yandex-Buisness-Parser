# Поток данных

## Схема

```
запросы × города
      ↓
центр города + сетка точек (geocoding.build_grid)
      ↓
браузер: карточки выдачи (browser_search)
      ↓
извлечение полей (extractors) → обогащение (enrichment)
      ↓
фильтры (без сайта, чёрный список, соцсети) + дедупликация (seen)
      ↓
событие «result» в интерфейс + запись raw
      ↓
этап 2: обработка (processing.process_all)
      ↓
Excel / CSV / JSON / карта
```

## Кто чем занят

- `runner.run_web()` — дирижёр: города, запросы, пауза, прогресс, финал.
- `browser_search` — открывает поиск Карт, листает выдачу, отдаёт карточки.
- `extractors` — вытаскивает название, категорию, адрес, телефон, сайт,
  рейтинг, отзывы, соцсети, координаты.
- `enrichment` — добирает данные с карточки, считает лид-скор, пишет
  событие результата.
- `exporters` — CSV/JSON/Excel/HTML-карта, общие правила колонок.
- `processing` — второй этап: группировка, фильтры, сохранение.

## Хранилище

- `output/` — служебные файлы: кэш страниц, `_seen.json`, чекпоинты,
  `.current_search.json`, история поисков.
- `results_root` — настраиваемая папка результатов (по умолчанию `output/`),
  внутри `raw/`, `processed/`, `archive/`.
- `logs/` — журналы прогонов (`ГГГГММДД_ЧЧММСС_…_Город.log`).
- `settings.json` — настройки приложения; `.env` — ключи.

## Память о найденном

`output/_seen.json` хранит организации, которые уже попадали в выгрузки.
Из-за этого повторный поиск по тому же городу может закончиться сообщением
«всё уже спарсено ранее» (`all_seen`). Это не ошибка: кэш чистится в
«Истории» → «Очистить кэш».

## Пауза и продолжение

`checkpoint.py` пишет позицию (город, запрос, точка, страница) и уже
собранные записи. «Пауза» завершает текущий шаг, сохраняет файл и
останавливает процесс; «Продолжить» передаёт `resume: true` и те же
параметры. Перезагрузка страницы не теряет паузу: `/status` возвращает
`paused.resume`.

## Сбой vs пустота

Разные исходы различаются явно:

- `stopped` — остановлено пользователем;
- `paused` — пауза с сохранённой позицией;
- `all_seen` — организации были, но все уже в кэше;
- `error` — прогон сломался, в логе есть причина;
- пустой список без флагов — «ничего не подошло под запрос».

Интерфейс обязан говорить разными словами, иначе «нашлось 0» выглядит как
поломка.
