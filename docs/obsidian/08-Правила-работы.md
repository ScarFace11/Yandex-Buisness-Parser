# Правила работы

Полная версия — `AGENTS.md` в корне. Здесь — суть для быстрого чтения.

## Договорённости пользователя

1. Коммитить свою работу всегда, не спрашивая.
2. В шапке разделять технические и пользовательские кнопки.
3. Шрифт не меньше 12px.
4. Второстепенные панели («Массовый обход») свёрнуты по умолчанию.
5. Координаты — в каждой выгрузке, иначе карта пустая.
6. Единая сетка: отступы из токенов, текст не «плывёт».
7. Простой язык без жаргона: «поиск», а не «парсер».
8. Пустой экран объясняет следующий шаг.
9. Длинный текст сворачивается: короткая строка + подробности по клику.
10. Разделы должны читаться: заголовок, ритм, граница — не одна полоска.
11. Ревью — как обычный пользователь, простыми словами.
12. Исправлять по пунктам, по шагам.
13. Обновлять тесты вместе с поведением, не ослаблять их.
14. Держать документацию в `docs/obsidian/` актуальной.

## Инженерные привычки

- Маленькие коммиты с префиксом (`feat`, `fix`, `style`, `refactor`).
- В теле — «почему», а не пересказ диффа.
- CSS: часть выбирается по блоку, порядок = каскад.
- JS: не менять порядок модулей.
- Токены вместо hex, `aria-label` у иконок, видимый фокус.
- Не трогать чужие правки и не пушить без просьбы.
- Настоящий парсинг — не способ проверки.

## Стиль текстов

- Коротко, по делу, без канцелярита.
- Ошибка говорит, что делать, а не только «ошибка».
- Подсказка стоит рядом с тем, к чему относится.
