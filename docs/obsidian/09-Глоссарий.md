# Глоссарий

**Прогон (run)** — один запуск поиска с текущими настройками: города,
запросы, фильтры.

**Raw** — сырые результаты сразу после сбора, до обработки. Лежат в
`raw/`, из них можно пересобрать выгрузку без повторного поиска.

**Processed** — обработанные записи: фильтры, объединение, оценка лида.

**Сетка точек** — набор координат внутри города, по которым открывается
выдача. Больше точек — полнее охват и дольше прогон.

**Точка** — один центр карты, вокруг которого листается выдача.

**Карточка** — страница организации на Яндекс.Картах.

**Обогащение** — добор полей с карточки: телефон, сайт, соцсети, рейтинг,
координаты.

**Лид-скор** — оценка 0–100, насколько организация похожа на клиента,
которому нужен сайт.

**Seen / «уже спарсено»** — глобальная память о найденных организациях;
повторно в выгрузку не попадают, пока кэш не очищен.

**Чекпоинт** — сохранённая позиция паузы: город, запрос, точка, страница.

**Пресет** — сохранённый набор настроек поиска, запускается одним кликом.

**Сфера** — вид бизнеса для запроса (кафе, стоматология, автосервис…).

**Массовый обход** — открытие профилей соцсетей пачкой с отметками
«Просмотрено».

**Док** — нижняя панель сайдбара с кнопкой запуска и подсказкой.

**Капча / SmartCaptcha** — проверка «Вы не робот?» от Яндекса; поиск
останавливается и честно сообщает причину.

**CDP** — Chrome DevTools Protocol, способ управлять настоящим браузером.
