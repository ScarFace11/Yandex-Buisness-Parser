# Архитектура

## Верхний уровень

| Слой | Где | Роль |
|---|---|---|
| Точка входа | `app.py` | Flask-приложение, порт, запуск браузера, `freeze_support()` для PyInstaller |
| HTTP API | `routes/api.py` | запуск/пауза/стоп, SSE-поток, статус, результаты, настройки |
| Публичный API | `routes/public_api.py` | внешние интеграции (n8n), ключи и лимиты |
| Файлы | `routes/parser.py` | папки результатов, скачивание, открытие в проводнике |
| Обновления | `routes/update.py` + `updater_helper.py` | проверка версии, скачивание, подмена exe |
| Диагностика | `routes/diagnostics.py` | самопроверка, отчёт о проблеме |
| Управление прогоном | `run_manager.py` | процесс-ребёнок, очередь, реестр прогонов, сторож |
| Парсер | `yandex_maps_parser/` | поиск, извлечение, обогащение, статистика, выгрузка |
| Хранилище путей | `paths.py` | `output/`, `logs/`, `settings.json`, `.env`, `static/` |
| Логи | `run_logger.py`, `console_io.py` | файлы прогонов, UTF-8 на Windows |

## Почему процессы, а не потоки

Парсинг держит браузер и сеть; Flask должен оставаться отзывчивым. Поэтому
`run_manager` запускает **отдельный процесс** с `runner.run_web(...)`, а
сообщения идут через `multiprocessing.Queue` → SSE. Так «Стоп» не ждёт
окончания страницы, а падение парсера не роняет сервер.

Сторож (`_PROCESS_TIMEOUT`, 15 минут тишины) принудительно завершает
зависший процесс. Мягкая остановка идёт через стоп-файл/событие, ребёнку
даётся время сохранить чекпоинт и Excel.

## Реестр прогонов

- `output/.current_search.json` — какой поиск считается «текущим»: вкладка
  «Текущий результат» читает только файлы после `started_at`.
- Реестр живёт в памяти `run_manager`; после перезагрузки страницы статус
  восстанавливается через `/status`.
- Пауза сохраняет позицию (город/точка/страница) в чекпоинте, «Продолжить»
  поднимает её из файла.

## Интерфейс

Один HTML (`templates/index.html`), модули JS `static/js/01-…13-…` без
сборщика, стили — 21 часть `static/css/00-…20-…`. Порядок подключения =
каскад. Подробности — [[03-Интерфейс]].

## Внешние зависимости

- Браузер на Chromium (Chrome/Edge/Яндекс/Chromium) — единственный
  источник страниц; поиск библиотек CDP в системе см. [[05-Поиск-и-браузер]].
- Leaflet (локально, `static/vendor/leaflet`) — вкладка «На карте».
- VK API — необязательный ключ: активность сообществ и бонус к оценке.
- Яндекс.Карты — без платных API-ключей, чтение страниц браузером.

## Границы ответственности

- `runner.py` не знает про HTTP и Flask: только `state`, очередь логов и
  callback прогресса.
- `run_manager.py` не знает, как парсить: только жизненный цикл процесса и
  события.
- Фронтенд не парсит данные: всё, что показывает таблица, приходит из
  `/results-view` и SSE-событий.
