# Поиск и браузер

## Зачем браузер

Яндекс.Карты отдают карточки только после выполнения JavaScript. Поэтому
приложение подключается к установленному браузеру на Chromium по
**Chrome DevTools Protocol** (`yandex_maps_parser/cdp_client.py`) и читает
уже отрисованную страницу. Платные API Яндекса не нужны.

Подойдёт Chrome, Edge, Яндекс Браузер, Brave, Chromium. Safari и Firefox не
умеют CDP — приложение скажет об этом баннером и не будет молча искать
впустую (`templates/index.html` → `#browser-notice`, `/status.browser_available`).

## Как идёт поиск

1. Для каждого города берётся центр и рамка (`geocoding`, `city_coords`).
2. Строится сетка точек (`build_grid`): круг по городу, шаг зависит от
   выбранного режима покрытия.
3. В каждой точке открывается выдача по запросу, карточки собираются по
   `data-object="search-list-item"` (до `_MAX_CARDS` на точку).
4. Выдача листается; дубли отсекаются по URL и глобальному `seen`.
5. Карточка обогащается: телефон, сайт, соцсети, рейтинг, координаты.
6. Результат сразу уходит в интерфейс и пишется в raw-файл.

## Антибот и ограничения

- `browser_search` распознаёт страницу «Вы не робот?» и помечает прогон как
  `SEARCH_BLOCKED`; интерфейс показывает причину, а не «0 результатов».
- `rate_limit.py` ограничивает частоту: слишком быстрый обход ускоряет капчу.
- Счётчики и лимиты по страницам/точкам видны в статистике прогона.
- При капче помогает пауза и смена запроса/города; приложение не обходит
  защиту автоматически.

## Пауза, стоп, сторож

- **Стоп** — мягкая остановка: сохраняется чекпоинт, финализируется Excel.
- **Пауза** — позиция (город, запрос, точка, страница) сохраняется; можно
  закрыть приложение и продолжить позже.
- Сторож в `run_manager` завершает процесс, если тот молчит 15 минут.

## Ограничения

- Поиск идёт по реальным страницам: результат зависит от текущей выдачи
  Яндекса и может меняться между запусками.
- «Ничего нового» — это про `output/_seen.json`, а не про отсутствие
  организаций. Кэш чистится в «Истории».
- Один и тот же город, разные запросы — разные выборки; дедупликация общая.
