# Руководство пользователя и FAQ

Это приложение для поиска организаций на Яндекс.Картах: собирает карточки,
разбирает контакты и соцсети, считает оценку лида и складывает результат в
Excel/CSV. Оно работает **на вашем компьютере**, слушает только `127.0.0.1` и
не отправляет данные на сторонние серверы.

## Что нужно

| Что | Зачем |
|---|---|
| Windows 10/11 x64 или macOS 12+ | приложение для рабочего стола |
| Chrome, Chromium, Edge, Brave или Яндекс Браузер | страницы Карт открываются настоящим браузером; Safari и Firefox не подходят |
| Свободный порт 5000 (Windows) / 5050 (macOS) | локальный интерфейс; на macOS 5000 занят AirPlay |
| Интернет | Карты и проверка обновлений |

Ключи Яндекса и 2ГИС не нужны. Для проверки активности ВКонтакте нужен свой
`VK_TOKEN` — без него эта функция просто не оценивается (и не штрафует лид).

## Установка на Windows

### Вариант 1. Установщик (рекомендуется)

1. Скачайте `YandexBusinessParser-windows-x64-setup.exe` со страницы
   [Releases](https://github.com/ScarFace11/Yandex-Buisnes-Parser/releases).
2. Запустите. Установка идёт **без администратора**, в
   `%LOCALAPPDATA%\Programs\YandexBusinessParser`.
3. Оставьте галочку «Создать ярлык на рабочем столе» — ярлык появится также в
   меню «Пуск».
4. Данные (результаты, логи, `.env`, настройки) живут отдельно, в
   `%APPDATA%\YandexBusinessParser`, и переживают обновление и удаление
   программы.

Удаление — «Параметры → Приложения → Яндекс Бизнес Парсер → Удалить». В конце
установщик спросит, удалить ли результаты и ключи; по умолчанию **нет**.

Если вы включили portable-режим у **установленной** копии (файл `.portable`
рядом с exe), данные лежат в папке программы и удаляются вместе с ней.
Установщик предупредит об этом и предложит отменить удаление — скопируйте
`output/`, `logs/`, `.env` и `settings.json` в надёжное место.

### Вариант 2. Portable (без установки)

Скачайте `YandexBusinessParser-windows-x64.zip`, распакуйте **в любую папку с
правом записи** (не в `Program Files`) и запустите
`YandexBusinessParser.exe`. Данные будут лежать рядом с exe, в папках `output/`
и `logs/`, — флешку с этой папкой можно переносить между компьютерами.

Чтобы установленная копия тоже работала как portable, создайте рядом с exe
пустой файл `.portable` или `portable.txt` — приложение будет хранить данные
рядом с exe, а не в AppData.

## Установка на macOS

1. Скачайте `.dmg` для своей архитектуры: `arm64` — Apple Silicon (M1–M4),
   `x64` — Intel.
2. Откройте образ и перетащите `YandexBusinessParser.app` в `Applications`.
3. Запустите приложение. Данные живут в
   `~/Library/Application Support/YandexBusinessParser`.

Если macOS не подписан, Gatekeeper покажет «Не удаётся открыть приложение» —
см. [FAQ](#gatekeeper-не-даёт-запустить-приложение).

## Первый поиск

1. Выберите город и введите запросы («стоматология», «автосервис», «кафе») или
   нажмите «Сферы» и выберите готовый набор.
2. В «Глубине поиска» задайте города, число страниц и лимит организаций.
3. Нажмите «Найти компании». Первый запуск может занять минуту: приложение
   подключается к браузеру.
4. Следите за вкладкой «Ход поиска». Если появилась капча — откройте окно
   браузера, решите её и вернитесь; сбор продолжится.
5. Результаты — во вкладке «Результаты», статистика — в «Статистике», файлы —
   в папке, указанной в «Куда сохранять».

## Обновление

Приложение само проверяет GitHub раз в 30 минут и показывает баннер под меню
навигации. Кнопка «Обновить сейчас» скачивает и ставит новую версию, после чего
приложение перезапускается.

- **Windows** — файлы заменяются автоматически; при сбое старая версия
  возвращается на место. Данные portable-копии (`output/`, `logs/`, `.env`,
  настройки рядом с exe) обновление не трогает.
- **macOS** — приложение скачивает `.dmg` и открывает его. Перетащите новое
  приложение в `Applications`, заменив старое.

Историю версий можно открыть кнопкой «Что нового» в шапке — даже когда
обновления нет. В списке у каждой версии краткое описание, а по нажатию на
неё открывается полный текст этой версии; «Назад» возвращает к списку.

## Где лежат данные

| Система | Режим | Папка |
|---|---|---|
| Windows | установщик | `%APPDATA%\YandexBusinessParser` |
| Windows | portable zip | папка с `YandexBusinessParser.exe` |
| Windows | portable-метка `.portable` | папка с exe, даже если сборка установлена |
| macOS | `.app` | `~/Library/Application Support/YandexBusinessParser` |

Внутри: `output/` — результаты и служебные файлы, `logs/` — журналы, `.env` —
ключи, `settings.json` — настройки. Папку результатов можно вынести отдельно:
«Куда сохранять» → «Обзор…».

## FAQ по типовым ошибкам

### SmartScreen: «Windows защитила ваш компьютер»

Так бывает у любого неподписанного установщика. Нажмите **«Подробнее»**, затем
**«Выполнить в любом случае»**. Скачивайте файл только со страницы Releases
этого репозитория. Если кнопки нет — правый клик по файлу → «Свойства» →
«Разблокировать» → «ОК».

### Gatekeeper не даёт запустить приложение

1. Откройте «Системные настройки» → «Конфиденциальность и безопасность».
2. Внизу нажмите «Всё равно открыть» рядом с сообщением о приложении.
3. Либо в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/YandexBusinessParser.app
   ```
   и запустите снова.

Это снимает карантин только с этого приложения; подпись Developer ID не
подменяется.

### Капча или «Подтвердите, что вы не робот»

Яндекс показывает проверку, если запросов слишком много или они идут слишком
часто.

1. Откройте окно браузера, которое использует приложение (Chrome/Яндекс
   Браузер), и решите капчу вручную.
2. Вернитесь в приложение и нажмите «Продолжить», если сбор на паузе.
3. Уменьшите число страниц/городов и параллельных вкладок, сделайте паузу
   10–15 минут.

Не запускайте несколько копий приложения одновременно с одного IP и не
используйте автокликеры капчи.

### 0 результатов

Проверьте по порядку:

1. **Браузер** — установлен ли Chrome/Chromium/Edge? Откройте «Диагностику»:
   без браузера сбор не начнётся.
2. **Город и запрос** — есть ли такая категория в выбранном городе; попробуйте
   более общий запрос и один город.
3. **Капча** — вкладка «Ход поиска» покажет предупреждение; решите её.
4. **Фильтры** — «Только без сайтов», обязательные соцсети, «Оценка лида ≥ 70»
   и чёрный список могут отсечь всё найденное. Нажмите «Применить фильтры
   заново» или сбросьте фильтры.
5. **Страницы** — при `MAX_PAGES = 1` и узкой категории выдача может быть
   пустой; увеличьте глубину.
6. **Карточки** — если включён разбор деталей, часть организаций без телефона
   или соцсетей может не попасть в итог при жёстких фильтрах.

Если в логе есть ошибка — скопируйте её из «Ход поиска» или приложите
`--check`-отчёт: «Диагностика» → «Скопировать отчёт».

### Excel: «Файл занят другим приложением»

Windows не даёт перезаписать открытый `.xlsx`.

1. Закройте книгу в Excel (проверьте, что не осталось процесса Excel в
   диспетчере задач).
2. Нажмите выгрузку ещё раз.
3. Если файл нужен открытым — сохраните результат под другим именем или
   закройте только эту книгу; приложение не может писать в заблокированный
   файл.

То же с CSV, если он открыт в Excel: закройте файл или выберите другую папку.

### Порт занят

Windows: `YP_PORT=5001` в `.env` или переменной окружения. macOS: приложение
само использует 5050, потому что 5000 занимает AirPlay. Если порт занят другой
копией — закройте её; вторая копия не должна работать с теми же файлами.

### «Браузер на Chromium не найден»

Установите Chrome, Edge, Brave, Chromium или Яндекс Браузер и перезапустите
приложение. Safari и Firefox не поддерживают Chrome DevTools Protocol.

   в баннере.

   вручную. Данные в AppData при этом не затрагиваются.

### Приложение не запускается после обновления

На Windows помощник обновления сам возвращает предыдущую версию, если замена
файлов не удалась. Журнал: `%APPDATA%\YandexBusinessParser\_update\update.log`
(или `_update\update.log` рядом с exe в portable-режиме). Пришлите последние
строки в issue.

## Что не стоит делать

- Запускать сбор по всей стране «в один поток» с максимальной глубиной: это
  долго, увеличивает риск капчи и создаёт нагрузку на Карты.
- Использовать собранные персональные данные без законного основания:
  ответственность за соблюдение 152-ФЗ и правил площадок лежит на
  пользователе.
- Ставить приложение в `Program Files` вручную: для установки используйте
  установщик, для portable — папку с правом записи.
