# Стили: карта частей

`style.css` больше нет — стили разбиты на упорядоченные части. **Порядок
подключения и есть каскад**: поздняя часть перекрывает раннюю. Поэтому
файлы названы с двумя цифрами и подключаются в `templates/index.html`
именно в этом порядке; тесты читают их тем же порядком (`tests/_css.py`).

| Часть | Что внутри |
|---|---|
| `00-tokens.css` | шрифт, CSS-токены, иконки |
| `01-header.css` | шапка, уведомления, прогресс, живая полоса |
| `02-layout-form.css` | каркас страницы, карточка, форма, пресеты, кнопка запуска |
| `03-tabs-log.css` | правая колонка, вкладки, журнал |
| `04-results-table.css` | таблица результатов, скачивание, фильтры, колонки |
| `05-controls.css` | переключатели соцсетей, источника, покрытия; тосты |
| `06-map-stats.css` | карта и графики статистики |
| `07-sender-city.css` | рассылка, бейдж версии, выбор города, сферы |
| `08-stats-updates.css` | статистика по городам, баннер обновления |
| `09-a11y-motion.css` | скроллбары, фокус, выделение, уменьшенное движение |
| `10-dark-responsive.css` | тёмная тема и адаптив |
| `11-redesign-sidebar.css` | редизайн: аккордеоны и фильтрация |
| `12-socials-empty.css` | плитки соцсетей, пустые состояния, валидация |
| `13-modals-history.css` | модалки, диагностика, отчёт о проблеме, история |

| `17-run-log.css` | панель хода поиска, уровни и фильтры журнала |

| `19-polish.css` | визуальная шлифовка: типографика, кнопки, поля |
| `20-terms-grid.css` | соглашение, хранение, единая сетка, живая сводка |

## Как править

1. Ищите правило по `grep -rn "селектор" static/css/`.
2. Новое правило кладите в часть, которая отвечает за блок. Если правило
   перекрывает старое (тема, адаптив, шлифовка), оно должно физически
   стоять **ниже** — то есть в той же или более поздней части.
3. Новую часть добавляйте в конец нумерации, ссылку — в конец списка в
   `templates/index.html`. Вставлять файл в середину нельзя без проверки
   каскада.
4. После правок: `pytest tests/test_ui_markup.py tests/test_theme_contrast.py`
   и `node --test tests/ui/*.test.mjs`.
